# AndresDev Portfolio

Angular portfolio SPA. The application lives at the repository root; `utilities/` holds provenance artifacts, audits and feature logs.

| Task | Command / path |
| --- | --- |
| Development server | `npm start` |
| Production build | `npm run build` |
| Unit tests | `npm test` |
| Static output | `dist/andresdev-portfolio/browser` |
| Deployment config | `vercel.json` |
